PESEL (*Powszechny Elektroniczny System Ewidencji Ludności*) to powszechny 11-cyfrowy numer ewidencyjny obywateli Polski. Koduje datę urodzenia posiadacza, stulecie urodzenia, płeć oraz seryjny numer porządkowy.

## Użycie

```php
use SlashLab\Numerik\Numerik;

// Boolowskie
Numerik::pesel()->isValid('92060512186');   // true

// Bogaty wynik
$result = Numerik::pesel()->validate('92060512186');
$result->isValid;   // true

// Parsowanie do obiektu wartości
$pesel = Numerik::pesel()->parse('92060512186');

// Null przy niepowodzeniu zamiast wyjątku
$pesel = Numerik::pesel()->tryParse('złe-wejście'); // null
```

## API obiektu wartości

`parse()` i `tryParse()` zwracają instancję `SlashLab\Numerik\ValueObjects\Pesel`.

### Podstawowe

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getRaw()` | `string` | Oryginalne wejście, bez zmian. |
| `getNormalized()` | `string` | Cyfry po usunięciu białych znaków. |
| `__toString()` | `string` | To samo co `getNormalized()`. |

### Wyodrębnione dane

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getBirthDate()` | `DateTimeImmutable` | Data urodzenia zdekodowana z PESEL. |
| `getGender()` | `Gender` | `Gender::Male` lub `Gender::Female`. |
| `getOrdinalNumber()` | `int` | 4-cyfrowy numer porządkowy (cyfry 7–10). Ostatnia cyfra koduje płeć: nieparzysta = mężczyzna, parzysta = kobieta. |
| `getCentury()` | `int` | Stulecie urodzenia jako rok bazowy, np. `1900`, `2000`, `2100`. |

### Narzędziowe

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `isMale()` | `bool` | `true` gdy płeć to `Gender::Male`. |
| `isFemale()` | `bool` | `true` gdy płeć to `Gender::Female`. |
| `getAge()` | `int` | Pełne lata od daty urodzenia do dzisiaj. |
| `isAdult()` | `bool` | `true` gdy `getAge() >= 18`. |

## Przykłady

```php
$pesel = Numerik::pesel()->parse('92060512186');

$pesel->getRaw();                         // '92060512186'
$pesel->getNormalized();                  // '92060512186'
$pesel->getBirthDate()->format('Y-m-d'); // '1992-06-05'
$pesel->getGender();                      // Gender::Female
$pesel->isFemale();                       // true
$pesel->getOrdinalNumber();               // 1218 (cyfry 7–10)
$pesel->getCentury();                     // 1900
$pesel->getAge();                         // obliczony od dzisiaj
$pesel->isAdult();                        // true
```

## Kodowanie stulecia

Cyfry miesiąca w PESEL kodują zarówno rzeczywisty miesiąc jak i stulecie urodzenia:

| Zapisany zakres miesięcy | Rzeczywisty miesiąc | Stulecie urodzenia |
|--------------------------|--------------------|--------------------|
| 01–12 | 01–12 | 1900–1999 |
| 21–32 | 01–12 | 2000–2099 |
| 41–52 | 01–12 | 2100–2199 |
| 61–72 | 01–12 | 2200–2299 |
| 81–92 | 01–12 | 1800–1899 |

## Powody błędów

| Powód | Wartość | Kiedy |
|-------|---------|-------|
| `InvalidLength` | `invalid_length` | Wejście nie ma dokładnie 11 cyfr po normalizacji. |
| `InvalidCharacters` | `invalid_characters` | Znaki niebędące cyframi pozostają po usunięciu białych znaków. |
| `InvalidMonth` | `invalid_month` | Kodowanie miesiąca nie odpowiada żadnemu ze znanych zakresów stulecia. |
| `InvalidDate` | `invalid_date` | Zdekodowana data nie jest prawdziwą datą kalendarzową. |
| `FutureDate` | `future_date` | Zdekodowana data urodzenia jest w przyszłości (tylko tryb ścisły). |
| `InvalidChecksum` | `invalid_checksum` | Cyfra kontrolna nie zgadza się z obliczoną wartością. |
| `AllSameDigit` | `all_same_digit` | Wszystkie 11 cyfr jest identycznych (tylko tryb ścisły). |

## Algorytm walidacji

Wagi: `1, 3, 7, 9, 1, 3, 7, 9, 1, 3`

1. Odrzuć wejścia dłuższe niż 32 znaki. Usuń białe znaki. Wymagaj dokładnie 11 cyfr.
2. Zdekoduj datę urodzenia używając powyższej tabeli kodowania stulecia. Sprawdź, że data jest prawdziwą datą kalendarzową. W trybie ścisłym odrzuć również daty urodzenia w przyszłości.
3. Oblicz sumę kontrolną: pomnóż każdą z pierwszych 10 cyfr przez jej wagę, zsumuj iloczyny, oblicz `mod 10`, odejmij od `10`, oblicz `mod 10` ponownie. Wynik musi być równy cyfrze 11.
4. W trybie ścisłym odrzuć wejścia, w których wszystkie 11 cyfr jest identycznych.

Zobacz [Algorytmy](/pl/guide/algorithms/) po pełną dokumentację.
