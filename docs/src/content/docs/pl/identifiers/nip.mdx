NIP (*Numer Identyfikacji Podatkowej*) to 10-cyfrowy numer identyfikacji podatkowej używany przez osoby fizyczne i prawne w Polsce.

## Użycie

```php
use SlashLab\Numerik\Numerik;

// Boolowskie
Numerik::nip()->isValid('5260250274');   // true

// Bogaty wynik
$result = Numerik::nip()->validate('5260250274');
$result->isValid;   // true

// Parsowanie do obiektu wartości
$nip = Numerik::nip()->parse('5260250274');

// Null przy niepowodzeniu zamiast wyjątku
$nip = Numerik::nip()->tryParse('złe-wejście'); // null
```

NIP akceptuje myślniki i spacje jako separatory wejścia:

```php
Numerik::nip()->isValid('526-025-02-74');   // true
Numerik::nip()->isValid('526 025 02 74');   // true
```

## API obiektu wartości

`parse()` i `tryParse()` zwracają instancję `SlashLab\Numerik\ValueObjects\Nip`.

### Podstawowe

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getRaw()` | `string` | Oryginalne wejście, bez zmian. |
| `getNormalized()` | `string` | 10 surowych cyfr (myślniki i spacje usunięte). |
| `__toString()` | `string` | To samo co `getNormalized()`. |

### Formatowanie i metadane

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getFormatted()` | `string` | Kanoniczna postać wyświetlana `NNN-NNN-NN-NN`. |
| `getFormattedAlternative()` | `string` | Alternatywna postać `NNN-NN-NN-NNN` używana przez niektóre dokumenty podmiotów prawnych. |
| `getTaxOfficeCode()` | `string` | Pierwsze 3 cyfry — wskazuje wystawiający urząd skarbowy. |

## Przykłady

```php
$nip = Numerik::nip()->parse('5260250274');

$nip->getRaw();                       // '5260250274'
$nip->getNormalized();                // '5260250274'
$nip->getFormatted();                 // '526-025-02-74'
$nip->getFormattedAlternative();      // '526-02-50-274'
$nip->getTaxOfficeCode();             // '526'

// Z sformatowanym wejściem
$nip = Numerik::nip()->parse('526-025-02-74');
$nip->getRaw();            // '526-025-02-74'
$nip->getNormalized();     // '5260250274'
```

## Powody błędów

| Powód | Wartość | Kiedy |
|-------|---------|-------|
| `InvalidLength` | `invalid_length` | Wejście nie ma dokładnie 10 cyfr po usunięciu separatorów. |
| `InvalidCharacters` | `invalid_characters` | Obecne są znaki inne niż cyfry, myślniki i spacje. |
| `InvalidFormat` | `invalid_format` | Pierwsze 3 cyfry to `000` (żaden prawidłowy urząd skarbowy nie ma kodu 000). |
| `InvalidChecksum` | `invalid_checksum` | Cyfra kontrolna nie zgadza się. |
| `AllSameDigit` | `all_same_digit` | Wszystkie cyfry są identyczne — tylko tryb ścisły. |

## Algorytm walidacji

Wagi: `6, 5, 7, 2, 3, 4, 5, 6, 7`

1. Usuń myślniki i spacje. Wymagaj dokładnie 10 cyfr.
2. Sprawdź, że pierwsze 3 cyfry to nie `000`.
3. Pomnóż każdą z pierwszych 9 cyfr przez jej wagę, zsumuj, oblicz `mod 11`. Wynik musi być równy cyfrze 10; ponieważ pojedyncza cyfra może przyjmować tylko wartości 0–9, wynik modulo równy `10` nigdy nie pasuje i zawsze kończy się błędem `InvalidChecksum`.

Zobacz [Algorytmy](/pl/guide/algorithms/) po pełną dokumentację.
