KRS (*Krajowy Rejestr Sądowy*) to numer rejestru sądowego nadawany podmiotom prawnym w Polsce. Jest to 10-cyfrowy sekwencyjny numer rejestru.

<Aside type="caution" title="Ograniczenie walidacji offline">
KRS nie posiada publicznie udokumentowanego algorytmu sumy kontrolnej. Numerik waliduje **wyłącznie format i strukturę** — nie może zweryfikować, czy dany numer KRS jest rzeczywiście przypisany w rejestrze. W celu autorytatywnej weryfikacji skorzystaj z oficjalnego [API rejestru KRS](https://prs.ms.gov.pl/krs/openApi).
</Aside>

## Użycie

```php
use SlashLab\Numerik\Numerik;

// Boolowskie
Numerik::krs()->isValid('0000127206');   // true

// Numery bez zer wiodących są akceptowane i normalizowane
Numerik::krs()->isValid('127206');       // true

// Bogaty wynik
$result = Numerik::krs()->validate('0000127206');
$result->isValid;   // true

// Parsowanie do obiektu wartości
$krs = Numerik::krs()->parse('0000127206');

// Null przy niepowodzeniu zamiast wyjątku
$krs = Numerik::krs()->tryParse('złe-wejście'); // null
```

## API obiektu wartości

`parse()` i `tryParse()` zwracają instancję `SlashLab\Numerik\ValueObjects\Krs`.

### Podstawowe

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getRaw()` | `string` | Oryginalne wejście, bez zmian. |
| `getNormalized()` | `string` | Surowe cyfry tak jak podane (bez dodatkowego dopełniania). |
| `__toString()` | `string` | To samo co `getNormalized()`. |

### Formatowanie i metadane

| Metoda | Typ zwracany | Opis |
|--------|-------------|------|
| `getFormatted()` | `string` | Dopełniony zerami do 10 cyfr, np. `0000127206`. |
| `getNumericValue()` | `int` | Numeryczna wartość całkowita numeru KRS. |

## Przykłady

```php
$krs = Numerik::krs()->parse('0000127206');

$krs->getRaw();           // '0000127206'
$krs->getNormalized();    // '0000127206'
$krs->getFormatted();     // '0000127206'
$krs->getNumericValue();  // 127206

// Skrócona forma — zera wiodące nie są wymagane na wejściu
$krs = Numerik::krs()->parse('127206');

$krs->getRaw();           // '127206'
$krs->getNormalized();    // '127206'
$krs->getFormatted();     // '0000127206'
$krs->getNumericValue();  // 127206
```

## Algorytm walidacji

KRS to sekwencyjny numer rejestru bez sumy kontrolnej. Walidacja jest wyłącznie strukturalna:

1. Usuń spacje. Wymagaj od 1 do 10 cyfr.
2. Sprawdź, że wszystkie pozostałe znaki są cyframi.
3. Sprawdź, że wartość numeryczna nie wynosi zero.

Numer, który przechodzi te sprawdzenia, jest **strukturalnie prawidłowy** — odpowiada formatowi KRS. Może, ale nie musi być faktycznie zarejestrowanym podmiotem.

## Powody błędów

| Powód | Wartość | Kiedy |
|-------|---------|-------|
| `InvalidLength` | `invalid_length` | Wejście ma więcej niż 10 cyfr po normalizacji. |
| `InvalidCharacters` | `invalid_characters` | Znaki niebędące cyframi pozostają po usunięciu białych znaków. |
| `AllZeros` | `all_zeros` | Wszystkie cyfry to zera — wartość numeryczna wynosi 0, co nie jest prawidłowym numerem rejestru. |
| `AllSameDigit` | `all_same_digit` | Wszystkie 10 cyfr jest identycznych — tylko tryb ścisły. |
